# Gnomski-Dom — «Пепел и Шишки»

Пиксельная дарк-фэнтези RPG для браузера. 18+: мат, кровь, медведи.

**Играть:** https://klim-mertens.github.io/Gnomski-Dom/ (после включения GitHub Pages, см. ниже)

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | ходить |
| ЛКМ / J | удар (3-й удар подряд — тяжёлый) |
| Пробел | перекат (неуязвимость) / дальше в диалоге |
| R | ярость, когда шкала полная (копится от полученного урона) |
| E | отдохнуть у костра, поговорить |
| 1–4 | распределить очки при повышении уровня |

## Что есть в прототипе

- Выбор из трёх героев (Вальдер, Эдрик, Ярка), двое других — спутники с ИИ.
- Лесная поляна, бой с Пустыми и гнилыми волками, кровь, трупы, хитстоп.
- Опыт, уровни, 4 характеристики.
- Костёр: отдых, сохранение, философские фразы.
- Отшельник и мини-игра «бутылки в сосну». Шестая бутылка всегда вонючая.

## Для разработки

```bash
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
```

Тексты — `src/data/texts.js`, баланс героев — `src/data/heroes.js`, пиксельные сетки спрайтов — `src/data/grids.js`.
Сохранение хранится в localStorage браузера и проверяется при загрузке (`src/systems/save.js`).
